## 🎙️서비스 소개
> 최근 드라마나 영화, 방송 프로그램을 보고 따라서 여행을 떠나는 'Set-Jetting' 현상이 전세계적으로 유행하고 있습니다.
> 
> 이런 관광 트렌드와 K-콘텐츠의 인기를 반영하여 한국 드라마, 영화 촬영지를 목적지로 삼는 여행객들을 위한 서비스를 만들게 되었습니다.
> 
> SPOT!은 한국 드라마·영화 촬영지를 쉽게 검색하고, 이를 기반으로 여행을 계획하고 기록할 수 있는 통합 여행 서비스입니다.
